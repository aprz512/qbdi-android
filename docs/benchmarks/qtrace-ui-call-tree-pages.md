# 调用树分页诊断（UI-02）

日期：2026-09-24。此结果来自当前开发机的本地诊断，不是固定性能参考主机门禁。

## 语料与方法

- 两个 QTRB 1.2 单文件语料，各 10,000 条 instruction、340,345 字节、5,000 个调用帧。
- 宽树交替写入 call/return，形成 5,000 个根帧；深树先写入 5,000 个 call，再写入 5,000 个 return，形成 5,000 层嵌套。
- 使用仓库 `scripts.tests.test_trace_binary` 和 `scripts.tests.test_flight_trace` 的 QTRB 编码辅助函数；call 的定义标志为 `5`，return 为 `9`。两份语料只保存在 `/tmp/qtrace-call-tree-corpus/`，不进入仓库。
- Release 构建在同一机器运行五轮。每轮打开 artifact，首次请求调用树；宽树依次读取 50 个根节点页，深树依次展开 5,000 层。逐页校验树身份，累计节点数恰为 5,000；记录首次构建耗时、服务端分页 p95 和序列化 JSON 最大字节数。

| 语料 | 五轮首次构建 ms | 中位数 ms | 五轮分页 p95 ms | 最大单页 JSON |
| --- | --- | ---: | --- | ---: |
| 宽树 | 51.095、51.636、51.970、52.271、51.150 | 51.636 | 0.012、0.012、0.013、0.011、0.015 | 18,881 B |
| 深树 | 60.692、60.014、57.139、57.757、57.881 | 57.881 | 均小于 0.001 | 357 B |

前端自动化测试以 100 个已加载根节点、10,000 个声明总节点验证：DOM 中调用帧始终少于 20 个；滚动到底部后按需请求下一页。Rust 测试检查身份、非法父节点、树切换和工作区关闭。此测量只证明新分页路径的上界与正确遍历；没有旧版相同语料的耗时对照。
