## 第 1 项：配置与前置诊断

旧 CLI 的缺字段错误只有 `app is missing field package`，没有说明接口与修正入口；
缺失 Frida bindings 时仍先构造 NDK inspector，实际 bindings 导入要等设备预检后才发生。
新增回归先在旧实现上观察到这两项失败，再验证修复。

`load_config` 继续使用原来的严格校验与错误码，仅给解析错误补 CLI/native 接口、字段及文档指引；
限制原始细节长度，使超长未知字段不会吞掉修正入口。`FridaProvider.check_host` 在会话构造前检查包是否存在，
不在父进程初始化 Frida；导入失败与版本不符另保留实际解释器、版本和排障入口。

实际子进程分别运行缺字段、错误类型、未知字段、native JSON 误传和 bindings 缺失五种输入。
每次退出码均为 1，stdout 为空；ADB sentinel 未被调用。错误、配置和检查保存在
`out/ux-handoff-20261022/cli/`。版本不符使用现有 FakeFridaProbe 回归验证，没有修改设备 server。
有效旧配置、缺字段/类型/未知字段及配置安全边界继续由原测试覆盖。
